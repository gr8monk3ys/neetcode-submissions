# Behavioral

Prep for "tell me about a time…" questions. The goal: a small set of strong,
reusable stories you can adapt on the fly.

## Files
- [`star_template.md`](star_template.md) — the format to write each story in.
- [`story_bank.md`](story_bank.md) — your stories, tagged by the themes they cover.
- [`common_questions.md`](common_questions.md) — questions to rehearse against.

## How to use
1. Brainstorm 6–8 real stories (projects, conflicts, failures, leadership).
2. Write each in STAR form in `story_bank.md`.
3. Map each story to the themes/questions it can answer — aim to cover the
   common questions with as few stories as possible.
4. Rehearse out loud; keep each answer to ~2 minutes.

## Tips
- Lead with the result, then explain how you got there if asked.
- Say "I" (your contribution), not "we", when describing what you did.
- Quantify impact wherever you can.
