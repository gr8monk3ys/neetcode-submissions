# Fundamentals

Short notes on the building blocks that come up in most designs. Add a file per
topic as you study (e.g. `caching.md`, `databases.md`).

Suggested topics:

- **Networking:** DNS, load balancers (L4/L7), CDNs, TCP vs UDP, HTTP/2, gRPC.
- **Databases:** SQL vs NoSQL, indexing, replication, sharding, partitioning.
- **Consistency:** CAP / PACELC, strong vs eventual, quorums, consensus (Raft/Paxos).
- **Caching:** cache-aside vs write-through, eviction policies, invalidation, hot keys.
- **Messaging:** queues vs streams, Kafka, pub/sub, delivery semantics, back-pressure.
- **Scaling:** horizontal vs vertical, statelessness, rate limiting, idempotency.
- **Storage:** object storage, write-ahead logs, LSM-trees vs B-trees.
- **Reliability:** replication, failover, health checks, circuit breakers, SLAs/SLOs.
- **Observability:** metrics, logs, traces, alerting.
- **Back-of-envelope:** "latency numbers every programmer should know", powers of two.
